# Certifications and Exams

Certificates support—not prove—principal or CTO ability. Take an exam only after building the corresponding systems.

| Priority | Credential/exam | When | What it signals | Required project evidence before attempting |
|---|---|---|---|---|
| High | Meta React Native Professional Certificate | Days 57–140 | Structured RN foundation | Two tested RN apps, one consuming an API |
| High | AWS Certified Developer – Associate | Days 176–240 | Cloud application fundamentals | Deployed backend, CI/CD, secrets and observability |
| High | Certified Kubernetes Application Developer (CKAD) | Post-Day 365 or optional Days 330+ | Container workload operations | Only if your product genuinely uses Kubernetes |
| Medium | GitHub Foundations | Days 1–90 | Git/GitHub workflow | 50 meaningful commits and 10 reviewed PRs |
| Medium | GitHub Actions certification | Days 176–260 | CI/CD automation | Reusable mobile/backend pipelines with security scanning |
| Medium | Google Associate Android Developer equivalent training/portfolio | Days 218–245 | Android capability | Confirm current exam availability before planning payment |
| Portfolio gate | Apple App Store release | Days 281–365 | Real iOS distribution | Signed, reviewed beta/public app with crash monitoring |
| Portfolio gate | Google Play release | Days 281–365 | Real Android distribution | Staged rollout, policy compliance and rollback plan |
| Advanced | AWS Solutions Architect – Associate | Post-Day 365 | Architecture breadth | Workload model, cost model, resilience tests |
| Advanced | ISC2 CC or Security+ | Post-Day 365 if security role needs it | Security vocabulary and controls | Threat models and MASVS-based mobile review |

## Rules

1. Verify current exam availability, syllabus, pricing and policies on the official provider site before paying.
2. Do not collect overlapping beginner certificates.
3. Publish a project evidence page beside every credential.
4. A failed exam becomes a diagnostic: record weak domains, build them, then retry.

## Stronger examinations you conduct yourself

- Quarterly six-hour build from a blank repository without AI.
- Quarterly architecture defense before two experienced engineers.
- Semiannual security review using OWASP MASVS and threat modelling.
- Semiannual performance lab with published workload, device matrix and traces.
- Annual public capstone, user metrics, postmortem and technical talk.
